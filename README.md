# 🚀 C+2 (cplus2)

**C++ with a built-in Borrow Checker. Backward compatible.** 

Keep C++ great.

---

`c+2` is a next-generation, memory-safe evolution of C++. It brings the strict safety guarantees of Rust's **Borrow Checker** directly into the C++ ecosystem—without sacrificing performance and with almost **No rewrite required** for your existing C++ codebases.
